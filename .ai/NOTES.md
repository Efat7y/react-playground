# Things I Learned

## useState

State updates trigger re-render.

State should never be mutated.

Always use setter functions.

---

## Props

Read only.

Passed from parent to child.

Never mutate props.

---

## JSX

JSX is syntax.

React converts JSX into JavaScript.

---

## Common Mistakes

Using push() instead of immutable updates.

Mutating state directly.

Calling event handlers immediately.

Using array index as key.
